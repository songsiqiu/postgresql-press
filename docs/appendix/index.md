# 附录

附录会放术语、学习提示和一些不适合塞进主线但很有用的内容。

## 你学完能干什么

- 知道遇到术语不懂时去哪里查
- 知道本站示例和练习题为什么这样写
- 能理解后续补内容时要遵守的口径

## 适合什么时候看

- 看到 `schema`、`MVCC`、`WAL` 这类词时，先看术语表
- 想知道为什么每章都有练习题时，看练习与示例规范
- 准备跨数据库迁移 SQL 时，看 SQL 兼容性
- 做表结构边界设计时，看 PostgreSQL 限制
- 后续继续翻译或补章节时，先看翻译规范和术语表

## 练习题

1. 遇到不懂的英文术语，先看哪一页？
2. 想知道练习题应该怎么写，先看哪一页？
3. 为什么示例表名要尽量统一？

::: tip 提示
附录不是主线学习内容，但能让整站读起来更一致。
:::

::: details 答案
1. 术语表。
2. 练习与示例规范。
3. 新手不用每页重新理解一套业务背景。
:::

## 常见坑

- 每章随意翻译术语，前后不一致
- 示例表名每页都换，读者很难跟上
- 练习题脱离当前章节内容

## 先记住这三句

- 附录负责统一口径。
- 术语要稳定，示例要连贯。
- 练习题要让读者能马上动手。
