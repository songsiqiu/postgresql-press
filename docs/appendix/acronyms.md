# 缩略词表

PostgreSQL 文档里有很多缩略词。先知道它们大概指什么，阅读时就不会频繁卡住。

## 你学完能干什么

- 能看懂常见缩略词的中文口径
- 知道哪些缩略词值得继续深入
- 避免把不同缩略词混成一类概念

## 可运行例子

读执行计划或管理文档时，你可能会同时看到：

```text
WAL、MVCC、JIT、FDW、SPI、PITR
```

不要急着全背。先知道它们分别属于日志恢复、并发控制、执行优化、外部数据、服务端接口、恢复方案。

## 容易混淆的词

| 缩略词 | 中文口径 | 先这样理解 |
| --- | --- | --- |
| WAL | 预写式日志 | 变更先写日志，方便恢复 |
| MVCC | 多版本并发控制 | 让读写尽量少互相阻塞 |
| JIT | 即时编译 | 复杂查询里减少部分计算成本 |
| FDW | 外部数据封装器 | 让 PostgreSQL 访问外部数据源 |
| SPI | SPI 接口 | 服务端代码内部执行 SQL 的接口 |
| PITR | 时间点恢复 | 恢复到某个历史时间点 |

## 练习题

1. WAL 和 PITR 哪个更偏日志基础，哪个更偏恢复方案？
2. MVCC 主要解决哪类问题？
3. FDW 通常和什么场景有关？

::: tip 提示
缩略词先按主题归类，比按字母硬背更好记。
:::

::: details 答案
1. WAL 更偏日志基础，PITR 更偏恢复方案。
2. 并发读写和事务可见性。
3. 访问外部数据源。
:::

## 常见坑

- 看到缩略词就跳过整段
- 把 WAL 当成普通业务日志
- 把 FDW 当成复制或备份方案

## 先记住这三句

- 缩略词先按主题归类。
- WAL、MVCC、JIT 是读官方文档的高频词。
- 不懂缩略词时先查术语表，再回到正文。
