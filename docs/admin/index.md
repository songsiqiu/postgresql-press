# 管理与运维

这一页保留为旧入口，实际内容已经合并到 [服务器管理](/server-admin/) 主线里。这里用更短的方式帮你判断该去哪里看。

## 你学完能干什么

- 知道运维类问题应该去服务器管理里找
- 能把备份、权限、日志、复制这些问题分开
- 不会把 SQL 写法问题和数据库运行问题混在一起

## 常见场景

| 问题 | 先看哪里 |
| --- | --- |
| 服务怎么启动和初始化 | 安装与初始化 |
| 连接数、日志、资源参数 | 配置参数 |
| 账号能连但没权限 | 权限与安全 |
| 数据要恢复 | 备份与恢复 |
| SQL 很慢或有等待 | 日志与排障、日常维护 |
| 想做主从或故障切换 | 复制与高可用 |

## 练习题

1. 想查“为什么应用账号不能更新表”，应该先看哪一页？
2. 想设计恢复方案，应该先看哪一页？
3. 高可用能替代备份吗？

::: tip 提示
运维问题先分类，再进入对应章节。不要一上来就改配置。
:::

::: details 答案
1. 权限与安全。
2. 备份与恢复。
3. 不能。
:::

## 常见坑

- 把连接失败、权限失败、SQL 写错都当成一类问题
- 只做主从，不做备份
- 遇到慢查询先乱调参数，不看执行计划和日志

## 先记住这三句

- 运维问题要先分类。
- 高可用不是备份。
- 日志和备份是数据库安全感的底座。
