# 默认权限

默认权限决定未来新建对象自动获得哪些权限。它适合解决“以后新建的表也要授权”的问题。

## 你学完能干什么

- 知道默认权限影响未来对象
- 能区分已有对象授权和未来对象授权
- 知道默认权限和创建者有关
- 能避免新表上线后应用突然没权限

## 为什么需要

你给已有表授权：

```sql
GRANT SELECT ON ALL TABLES IN SCHEMA public TO readonly;
```

这只处理已经存在的表。以后新建的表，还需要默认权限：

```sql
ALTER DEFAULT PRIVILEGES IN SCHEMA public
GRANT SELECT ON TABLES TO readonly;
```

## 注意创建者

默认权限和“谁创建对象”有关。如果不同角色都会建表，要确认默认权限设置在正确的创建者上下文里。

## 容易混淆的词

| 词 | 新手解释 |
| --- | --- |
| 已有对象权限 | 对已经存在的表、序列等授权 |
| 默认权限 | 对未来新建对象的授权规则 |
| 创建者 | 新对象是谁创建的 |
| schema | 权限规则生效的模式范围 |

## 练习题

1. 默认权限影响已有表还是未来新建表？
2. 给已有表授权后，新建表一定自动有同样权限吗？
3. 默认权限是否和对象创建者有关？
4. 应用新表没权限时，是否应该检查默认权限？

::: tip 提示
已有对象和未来对象要分开授权。
:::

::: details 答案
1. 未来新建表。
2. 不一定。
3. 有关。
4. 应该。
:::

## 常见坑

- 只给已有表授权，忘记未来新表
- 不知道默认权限和创建者有关
- 切换迁移账号后默认权限失效
- 表授权了，但序列没有授权

## 先记住这三句

- 默认权限管未来对象。
- 已有对象要单独授权。
- 谁创建对象很重要。
