# 入门

这一组内容不是官方文档的原始顺序，而是给新手安排的学习顺序。

先把日常开发中最常遇到的问题学会，再回到完整官方目录里补细节。

## 你学完能干什么

- 知道新手应该先读哪几章
- 能区分 SQL、事务、索引分别解决什么问题
- 知道什么时候该回到官方主线继续补细节

## 第一阶段：先能用

1. [基础入门](/guide/getting-started)：知道 PostgreSQL 是什么，怎么连接，怎么建库建表
2. [SQL 核心](/guide/sql)：会查询、插入、修改、删除、关联和统计
3. [事务与并发](/guide/transaction)：知道提交、回滚、锁和并发冲突
4. [索引与性能](/guide/performance)：知道为什么查询会慢，怎么先看执行计划

## 第二阶段：回到官方主线

学完第一阶段后，再按下面顺序补：

1. [官方教程中文改造](/tutorial/)
2. [SQL 语言](/sql-language/)
3. [服务器管理](/server-admin/)
4. [客户端接口](/client-interfaces/)
5. [服务端编程](/server-programming/)
6. [内部原理](/internals/)

## 练习题

1. 新手第一阶段应该先读哪四页？
2. 想学查询、插入、修改和删除，应该先看哪一页？
3. 想知道查询为什么慢，应该先看哪一页？

::: tip 提示
入门路线先解决“能用”，再回到完整官方主线补细节。
:::

::: details 答案
1. 基础入门、SQL 核心、事务与并发、索引与性能。
2. SQL 核心。
3. 索引与性能。
:::

## 常见坑

- 一上来直接读完整参考手册
- 还不会查询就先学复杂内部原理
- 学 SQL 时跳过事务和索引，后面排查问题会吃力

## 先记住这三句

- 先能用，再补全。
- SQL、事务、索引是新手第一阶段的核心。
- 官方主线适合在有基础后继续系统学习。
