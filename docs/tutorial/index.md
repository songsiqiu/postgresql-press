# 官方教程中文改造

这一部分对应 PostgreSQL 官方 Tutorial。这里不会只是翻译语句，而是把操作顺序整理成新手能跟着做的步骤。

## 你学完能干什么

- 知道第一次接触 PostgreSQL 应该先做什么
- 能从第一条 SQL 进入后续学习路线
- 能理解教程和参考手册的区别

## 这一组内容解决什么

- 让你从安装到第一条 SQL 走通一遍
- 让你知道命令行和数据库之间怎么连接
- 让你对“创建、查询、修改、删除”先有实际手感

## 翻译原则

- 保留官方主题，不乱换语义
- 先讲操作目的，再讲命令
- 术语先解释，再继续往下读

## 练习题

1. 教程页适合第一次学习，还是适合查完整语法？
2. 跑通第一条 SQL 后，下一步建议看哪里？
3. 为什么教程不应该一开始堆很多术语？

::: tip 提示
教程的目标是带你走完第一遍流程，参考手册才适合查细节。
:::

::: details 答案
1. 适合第一次学习。
2. 基础入门和 SQL 核心。
3. 新手还没有场景，术语太多会打断理解。
:::

## 常见坑

- 把教程当完整参考手册
- 第一遍没跑通就急着学性能优化
- 只复制命令，不观察结果

## 先记住这三句

- 教程先让你跑通。
- 跑通之后再补概念。
- 参考手册用来查细节。
