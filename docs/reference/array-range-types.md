# 数组与范围类型速查

数组和范围都是 PostgreSQL 比较有特色的类型。数组保存多个值，范围保存一个连续区间。

## 你学完能干什么

- 能区分数组和范围
- 知道数组适合保存小范围多值属性
- 知道范围适合时间段和数值区间
- 能避免用数组或范围逃避正常建模

## 数组例子

```sql
CREATE TABLE articles (
  id bigserial PRIMARY KEY,
  tags text[] NOT NULL DEFAULT '{}'
);
```

`tags` 是文本数组。

## 范围例子

```sql
CREATE TABLE bookings (
  id bigserial PRIMARY KEY,
  room_id bigint NOT NULL,
  during tstzrange NOT NULL
);
```

`during` 表示一个带时区时间范围。

## 容易混淆的词

| 词 | 新手解释 |
| --- | --- |
| 数组 | 一个字段里保存多个同类型值 |
| 范围 | 一个连续区间 |
| `text[]` | 文本数组 |
| `tstzrange` | 带时区时间范围 |

## 练习题

1. `text[]` 是文本还是文本数组？
2. 时间段适合考虑范围类型吗？
3. 数组适合替代所有一对多关系吗？
4. 范围类型要不要注意边界？

::: tip 提示
数组看“多个值”，范围看“从哪里到哪里”。
:::

::: details 答案
1. 文本数组。
2. 适合。
3. 不适合。
4. 要。
:::

## 常见坑

- 用数组逃避一对多关系建表
- 不检查范围边界是否包含端点
- 数组或范围查询没考虑索引
- 把空数组、空范围和 `NULL` 混在一起

## 先记住这三句

- 数组保存多个值。
- 范围保存连续区间。
- 复杂关系仍要认真建模。
