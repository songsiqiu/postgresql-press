# 序列函数速查

序列函数用来取下一个编号、查看当前编号或设置编号位置。它们常和自增主键一起出现。

## 你学完能干什么

- 能理解 `nextval` 的作用
- 知道 `currval` 依赖当前会话
- 能用 `setval` 调整序列位置
- 能避免以为序列值一定连续

## 常见函数

```sql
SELECT nextval('order_no_seq');
```

取下一个序列值。

```sql
SELECT currval('order_no_seq');
```

取当前会话最近一次从这个序列拿到的值。

```sql
SELECT setval('order_no_seq', 2000);
```

把序列位置设置到指定值附近。

## 容易混淆的词

| 词 | 新手解释 |
| --- | --- |
| `nextval` | 取下一个值 |
| `currval` | 当前会话最近拿到的值 |
| `setval` | 设置序列位置 |
| 跳号 | 编号中间出现空缺 |

## 练习题

1. `nextval` 会不会推进序列？
2. `currval` 能在当前会话没取过值时随便用吗？
3. `setval` 常用来调整什么？
4. 序列能保证业务编号绝对连续吗？

::: tip 提示
序列重点是生成唯一递增值，不是保证没有空洞。
:::

::: details 答案
1. 会。
2. 不能，通常需要当前会话先调用过 `nextval`。
3. 序列当前位置。
4. 不能。
:::

## 常见坑

- 以为回滚会回收序列值
- 手工插入大编号后不调整序列
- 把 `currval` 当成全局当前值
- 用序列保证无跳号业务流水

## 先记住这三句

- `nextval` 取并推进。
- `currval` 看当前会话最近值。
- 序列不保证连续无跳号。
