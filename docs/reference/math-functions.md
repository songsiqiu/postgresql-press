# 数学函数速查

数学函数常用于金额计算、统计报表和数值处理。新手先掌握取整、绝对值、四舍五入和随机数。

## 你学完能干什么

- 能找到常用数学函数入口
- 能区分取整、四舍五入和截断
- 知道金额计算要认真选择类型和精度
- 能避免把展示格式和真实数值混在一起

## 常用入口

| 函数 | 用途 |
| --- | --- |
| `abs(x)` | 绝对值 |
| `round(x, n)` | 四舍五入到 n 位 |
| `floor(x)` | 向下取整 |
| `ceil(x)` | 向上取整 |
| `trunc(x, n)` | 截断到 n 位 |
| `power(x, y)` | 幂运算 |
| `random()` | 随机数 |

## 常见例子

```sql
SELECT round(19.876::numeric, 2) AS price;
```

结果是：

```text
19.88
```

如果业务没有明确要求，不要擅自改变后端返回的数值精度。

## 容易混淆的词

| 词 | 新手解释 |
| --- | --- |
| 四舍五入 | 按规则进位 |
| 截断 | 直接切掉多余位数 |
| 向下取整 | 往更小的整数走 |
| 向上取整 | 往更大的整数走 |

## 练习题

1. 求绝对值用哪个函数？
2. 四舍五入到 2 位可以用哪个函数？
3. `trunc` 和 `round` 是一回事吗？
4. 金额字段通常应该随便用浮点数吗？

::: tip 提示
数值处理先分清是计算规则，还是展示格式。
:::

::: details 答案
1. `abs`。
2. `round(x, 2)`。
3. 不是，`trunc` 是截断，`round` 是四舍五入。
4. 不应该，金额通常要认真选择精确数值类型。
:::

## 常见坑

- 把截断当成四舍五入
- 没有业务确认就改变数值精度
- 金额计算随意使用不合适的类型
- 在数据库里做过多展示格式处理

## 先记住这三句

- 数学函数要配合业务规则。
- 截断不是四舍五入。
- 数值精度不能擅自改。
