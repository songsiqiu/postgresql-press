# PostgreSQL 客户端应用速查

客户端应用是 PostgreSQL 自带或生态里常见的命令行工具，用来连接、导入导出、备份恢复或维护数据库。

## 你学完能干什么

- 知道哪些工具是在客户端机器上运行
- 能区分 `psql`、`pg_dump`、`pg_restore`、`createdb`
- 知道查问题时先选哪个工具入口

## 可运行例子

```bash
psql -h localhost -p 5432 -U app_user -d app_db
```

这条命令表示：用 `psql` 连接本机 `5432` 端口上的 `app_db` 数据库。

常见客户端工具：

| 工具 | 用途 |
| --- | --- |
| `psql` | 交互式执行 SQL |
| `pg_dump` | 导出一个数据库 |
| `pg_restore` | 恢复自定义格式备份 |
| `createdb` | 创建数据库 |
| `dropdb` | 删除数据库 |
| `createuser` | 创建角色 |

## 容易混淆的词

| 词 | 区别 |
| --- | --- |
| 客户端应用 | 从外部连接数据库的工具 |
| 服务器应用 | 管理或控制 PostgreSQL 服务的工具 |
| SQL 命令 | 在数据库连接里执行的命令 |
| shell 命令 | 在操作系统终端执行的命令 |

## 练习题

1. 交互式执行 SQL 常用哪个工具？
2. `pg_dump` 主要用来做什么？
3. `createdb` 是 SQL 命令还是 shell 命令？

::: tip 提示
看到命令前面没有 SQL 连接提示符，通常先把它当作 shell 命令看。
:::

::: details 答案
1. `psql`。
2. 导出数据库备份。
3. shell 命令。
:::

## 常见坑

- 把 `psql` 里的 SQL 命令和终端命令混用
- 导出后没有做恢复验证
- 在生产环境误用删除类工具

## 先记住这三句

- 客户端工具从外部连接数据库。
- `psql` 用来执行和验证 SQL。
- 备份工具要配合恢复验证才可靠。
