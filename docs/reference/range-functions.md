# 范围函数与操作符速查

范围类型用来表示一段连续区间，例如时间范围、数字范围。范围操作符能直接判断包含、重叠和边界。

## 你学完能干什么

- 能理解范围值的基本含义
- 知道如何判断区间是否重叠
- 能看懂包含关系操作符
- 能避免忽略开闭边界

## 一个范围例子

```sql
SELECT int4range(1, 5);
```

默认表示从 1 到 5 的整数范围，边界规则要看具体类型和写法。

判断重叠：

```sql
SELECT int4range(1, 5) && int4range(4, 8);
```

结果是 `true`。

判断包含：

```sql
SELECT int4range(1, 5) @> 3;
```

结果是 `true`。

## 常见操作符

| 写法 | 新手解释 |
| --- | --- |
| `range @> value` | 范围是否包含某个值 |
| `range1 && range2` | 两个范围是否重叠 |
| `lower(range)` | 取下边界 |
| `upper(range)` | 取上边界 |

## 容易混淆的词

| 词 | 新手解释 |
| --- | --- |
| 范围 | 一个连续区间 |
| 下边界 | 区间开始位置 |
| 上边界 | 区间结束位置 |
| 重叠 | 两个区间有交集 |

## 练习题

1. `&&` 在范围里常用来判断什么？
2. `@>` 可以判断范围是否包含某个值吗？
3. `lower(range)` 取上边界还是下边界？
4. 使用范围类型时为什么要注意开闭边界？

::: tip 提示
范围类型最适合处理“从哪里到哪里”的问题。
:::

::: details 答案
1. 是否重叠。
2. 可以。
3. 下边界。
4. 边界是否包含会影响结果。
:::

## 常见坑

- 不看清开闭边界
- 用两个普通字段手写复杂重叠判断
- 忽略范围索引和查询方式
- 把空范围和 `NULL` 混成一回事

## 先记住这三句

- 范围表达连续区间。
- `&&` 判断重叠。
- 边界规则一定要看清。
