# 统计视图速查

统计视图能帮助你了解数据库正在发生什么。新手不用背完整视图列表，先按排查问题分类。

## 你学完能干什么

- 知道统计视图能帮助排查什么
- 能按连接、表、索引、复制、慢查询方向找入口
- 能理解统计视图是观察工具，不是直接修复工具

## 常见观察方向

| 想看什么 | 方向 |
| --- | --- |
| 当前连接和正在执行的 SQL | 活动会话相关视图 |
| 表扫描和行变化 | 表统计相关视图 |
| 索引使用情况 | 索引统计相关视图 |
| 复制状态 | 复制相关视图 |
| 查询统计 | 扩展或统计视图提供的查询维度 |

## 怎么使用

排查时先问：

1. 是连接问题、慢查询、锁等待，还是复制延迟？
2. 需要看当前状态，还是历史趋势？
3. 是否需要结合日志和执行计划一起看？

统计视图通常只能告诉你现象和线索，不能单独给出完整答案。

## 练习题

1. 统计视图主要是观察工具还是修改工具？
2. 想看当前正在执行的 SQL，应该找哪类视图？
3. 统计视图能完全替代日志吗？
4. 排查慢查询为什么还要结合执行计划？

::: tip 提示
统计视图给线索，执行计划和日志帮你继续定位。
:::

::: details 答案
1. 观察工具。
2. 活动会话相关视图。
3. 不能。
4. 统计视图能看到现象，执行计划能看到具体执行路线。
:::

## 常见坑

- 只看统计视图，不看时间范围
- 把累计统计当成当前瞬间状态
- 不结合日志、SQL 和执行计划

## 先记住这三句

- 统计视图帮你观察数据库。
- 排查要结合日志和执行计划。
- 先分类问题，再找对应视图。
