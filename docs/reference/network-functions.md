# 网络地址函数速查

网络地址函数用于处理 `inet`、`cidr`、`macaddr` 这类网络相关类型。它们适合保存和判断 IP 地址、网段和包含关系。

## 你学完能干什么

- 知道 PostgreSQL 有网络地址类型
- 能判断 IP 是否属于某个网段
- 能看懂常见网络操作符
- 能避免把 IP 一律当普通文本处理

## 一个例子

```sql
SELECT inet '192.168.1.10' << cidr '192.168.1.0/24';
```

结果是 `true`，表示这个 IP 在这个网段内。

取网络地址：

```sql
SELECT network(inet '192.168.1.10/24');
```

## 常见写法

| 写法 | 新手解释 |
| --- | --- |
| `inet '192.168.1.10'` | IP 地址 |
| `cidr '192.168.1.0/24'` | 网段 |
| `addr << network` | 地址是否严格包含在网段内 |
| `network(addr)` | 取地址所属网络 |

## 容易混淆的词

| 词 | 新手解释 |
| --- | --- |
| `inet` | IP 地址或带掩码地址 |
| `cidr` | 网络地址块 |
| 网段 | 一组 IP 地址范围 |
| 包含关系 | 某个地址是否落在某个网段内 |

## 练习题

1. `inet` 适合保存 IP 地址吗？
2. `cidr '192.168.1.0/24'` 表示单个地址还是网段？
3. 判断 IP 是否属于网段时，把 IP 当普通文本方便吗？
4. 网络地址类型能帮助做包含判断吗？

::: tip 提示
涉及 IP 和网段时，优先考虑网络地址类型，不要全靠字符串。
:::

::: details 答案
1. 适合。
2. 网段。
3. 不方便，也容易出错。
4. 能。
:::

## 常见坑

- 把 IP 存成普通文本后手写比较
- 混淆单个 IP 和网段
- 不理解掩码含义
- 忽略网络类型自带的操作符

## 先记住这三句

- `inet` 保存 IP。
- `cidr` 表示网段。
- 网络类型能直接判断包含关系。
