# 聚合函数速查

聚合函数把多行数据汇总成统计结果。它们常和 `GROUP BY`、`FILTER`、`ORDER BY` 一起使用。

## 你学完能干什么

- 能查到常见聚合函数的用途
- 能区分计数、求和、平均、最大最小
- 知道什么时候要配合分组和过滤

## 常用入口

| 函数 | 用途 |
| --- | --- |
| `count(*)` | 统计行数 |
| `sum(amount)` | 求和 |
| `avg(score)` | 平均值 |
| `min(created_at)` | 最小值 |
| `max(created_at)` | 最大值 |
| `array_agg(id)` | 聚合成数组 |
| `string_agg(name, ',')` | 聚合成字符串 |

## 常见例子

```sql
SELECT
  user_id,
  count(*) AS total,
  max(created_at) AS latest_time
FROM notes
GROUP BY user_id;
```

这类 SQL 常用于后台列表、报表和统计接口。

## 容易混淆的词

| 词 | 新手解释 |
| --- | --- |
| `sum` | 求总和 |
| `avg` | 求平均 |
| `min` / `max` | 求最小或最大 |
| `array_agg` | 把多行收成数组 |
| `string_agg` | 把多行文本拼成一个字符串 |

## 练习题

1. 统计行数通常用哪个函数？
2. 求订单金额总和通常用哪个函数？
3. 想拿最近创建时间，可以用 `min` 还是 `max`？
4. 把多行名称拼成一个字符串，可以用哪个函数？

::: tip 提示
先判断你想要“数量、总和、平均、最大最小，还是收集成一组”。
:::

::: details 答案
1. `count(*)`。
2. `sum(amount)`。
3. `max(created_at)`。
4. `string_agg`。
:::

## 常见坑

- 忘记分组，导致全表只得到一行统计
- 对可能为 `NULL` 的字段求和后没有处理空结果
- 把聚合排序和最终结果排序混在一起
- 在应用层循环做本该由数据库完成的统计

## 先记住这三句

- 聚合函数负责汇总。
- 分组决定按谁分别统计。
- 统计 SQL 要先想清楚口径。
