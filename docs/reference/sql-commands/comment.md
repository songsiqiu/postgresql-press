# COMMENT 速查

`COMMENT` 用来给数据库对象添加说明。它不会改变数据行为，但能帮助团队理解对象用途。

## 你学完能干什么

- 能给表和列添加注释
- 知道注释服务理解和维护
- 能区分注释和约束
- 能避免只靠注释表达数据规则

## 给表加注释

```sql
COMMENT ON TABLE notes IS '用户笔记表';
```

给列加注释：

```sql
COMMENT ON COLUMN notes.title IS '笔记标题';
```

清除注释：

```sql
COMMENT ON TABLE notes IS NULL;
```

## 适合写什么

- 表表示什么业务对象
- 列的业务含义
- 枚举值或状态值说明
- 特殊约束背后的原因

## 容易混淆的词

| 词 | 新手解释 |
| --- | --- |
| 注释 | 给对象写说明 |
| 约束 | 数据必须满足的规则 |
| 元数据 | 描述结构的信息 |
| 对象 | 表、列、函数、模式等数据库元素 |

## 练习题

1. `COMMENT` 会改变表里的数据吗？
2. 给列加注释用 `COMMENT ON TABLE` 还是 `COMMENT ON COLUMN`？
3. 注释能替代 `NOT NULL` 约束吗？
4. 清除注释可以把注释设成什么？

::: tip 提示
注释负责解释，约束负责保护数据。
:::

::: details 答案
1. 不会。
2. `COMMENT ON COLUMN`。
3. 不能。
4. `NULL`。
:::

## 常见坑

- 用注释代替数据库约束
- 注释写得像口号，不说明真实含义
- 表结构改了，注释没有同步
- 只给表注释，不给关键列注释

## 先记住这三句

- 注释帮助理解对象。
- 注释不是数据规则。
- 结构变化后要同步更新注释。
