# COPY 速查

`COPY` 用来批量导入或导出数据。它比一行一行 `INSERT` 更适合处理大量数据。

## 你学完能干什么

- 知道 `COPY` 适合批量数据
- 能区分导入和导出方向
- 理解导入前要先校验数据
- 能避免直接把脏数据导入正式表

## 导出数据

```sql
COPY notes (id, title)
TO '/tmp/notes.csv'
WITH (FORMAT csv, HEADER true);
```

这会把 `notes` 表里的部分列导出成 CSV 文件。

## 导入数据

```sql
COPY demo_tags (name)
FROM '/tmp/tags.csv'
WITH (FORMAT csv, HEADER true);
```

导入前要确认文件格式、列顺序、编码和约束是否匹配。

## 容易混淆的词

| 词 | 新手解释 |
| --- | --- |
| `COPY FROM` | 从文件导入到表 |
| `COPY TO` | 从表导出到文件 |
| CSV | 常见表格文本格式 |
| 暂存表 | 先接收原始数据、再清洗入正式表的表 |

## 练习题

1. `COPY FROM` 是导入还是导出？
2. `COPY TO` 会把数据写到表里吗？
3. 大批量数据适合一行行 `INSERT`，还是优先考虑 `COPY`？
4. 为什么导入正式表前建议先校验数据？

::: tip 提示
记方向：`FROM` 是从外部进表，`TO` 是从表到外部。
:::

::: details 答案
1. 导入。
2. 不会，它是导出。
3. 优先考虑 `COPY`。
4. 避免格式错误或脏数据直接进入正式表。
:::

## 常见坑

- 把 `FROM` 和 `TO` 方向看反
- 文件列顺序和表列顺序不一致
- 没清洗就导入正式表
- 忽略权限、路径和服务器端文件位置

## 先记住这三句

- `COPY` 适合批量导入导出。
- `FROM` 进表，`TO` 出表。
- 导入前先校验数据。
