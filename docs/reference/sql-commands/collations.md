# CREATE COLLATION 与 DROP COLLATION 速查

排序规则决定文本如何比较和排序。`CREATE COLLATION` 用来创建排序规则，`DROP COLLATION` 用来删除排序规则。

## 你学完能干什么

- 知道排序规则影响文本比较
- 能理解排序规则和编码不同
- 知道创建排序规则前要评估兼容性
- 能避免上线后才发现排序结果不符合预期

## 使用排序规则

创建排序规则的具体选项和操作系统、ICU 支持有关。新手先看使用方式：

```sql
SELECT name
FROM users
ORDER BY name COLLATE "C";
```

这表示按指定排序规则排序。

删除排序规则：

```sql
DROP COLLATION custom_collation;
```

删除前要确认有没有列、索引或查询依赖它。

## 容易混淆的词

| 词 | 新手解释 |
| --- | --- |
| 排序规则 | 文本如何比较和排序 |
| 编码 | 字符如何保存 |
| ICU | 常见国际化规则库 |
| 依赖 | 哪些对象或查询使用了这个规则 |

## 练习题

1. 排序规则会影响 `ORDER BY name` 吗？
2. 排序规则和字符编码是一回事吗？
3. 删除排序规则前要确认依赖吗？
4. 不同环境的排序规则可能导致结果不同吗？

::: tip 提示
文本排序问题先看排序规则，不要只看编码。
:::

::: details 答案
1. 会。
2. 不是。
3. 要。
4. 可能。
:::

## 常见坑

- 把排序规则和编码混成一回事
- 不同环境排序结果不一致
- 删除排序规则前不查依赖
- 文本索引和排序规则关系没确认

## 先记住这三句

- 排序规则管文本怎么比较。
- 编码管字符怎么保存。
- 排序规则变化要评估依赖。
