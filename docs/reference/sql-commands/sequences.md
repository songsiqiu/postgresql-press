# CREATE SEQUENCE 与 ALTER SEQUENCE 速查

序列用来生成递增值，常用于主键或业务编号。它生成的是“下一个值”，不保证一定连续。

## 你学完能干什么

- 知道序列用来生成编号
- 能创建一个简单序列
- 知道如何调整序列起点
- 能避免把序列当成连续业务流水号保证

## 创建序列

```sql
CREATE SEQUENCE order_no_seq START 1000;
```

取下一个值：

```sql
SELECT nextval('order_no_seq');
```

调整序列：

```sql
ALTER SEQUENCE order_no_seq RESTART WITH 2000;
```

## 为什么可能不连续

- 事务回滚后，已经取过的序列值不会自动回收
- 缓存或并发会让编号出现跳号
- 删除数据不会让序列自动倒退

## 容易混淆的词

| 词 | 新手解释 |
| --- | --- |
| 序列 | 生成递增值的对象 |
| `nextval` | 取下一个序列值 |
| 跳号 | 编号中间缺了一些值 |
| 身份列 | 表字段自动使用序列生成值的一种写法 |

## 练习题

1. 序列主要用来生成什么？
2. 事务回滚后，序列值一定会回退吗？
3. `nextval` 是查看当前值还是取下一个值？
4. 序列适合保证业务编号绝对连续吗？

::: tip 提示
序列适合生成唯一递增值，不适合保证没有跳号。
:::

::: details 答案
1. 递增编号。
2. 不一定，通常不会回退已取的值。
3. 取下一个值。
4. 不适合。
:::

## 常见坑

- 把序列当成连续业务流水号保证
- 手工插入大 ID 后忘记同步序列
- 以为删除数据会重置序列
- 不理解回滚后序列值可能跳号

## 先记住这三句

- 序列生成下一个值。
- 序列不保证无跳号。
- 手工改数据后要留意序列位置。
