# DECLARE、FETCH、CLOSE 速查

游标用来分批读取查询结果。它适合处理较大的结果集，但通常要放在事务里使用。

## 你学完能干什么

- 知道游标用于分批读取
- 能看懂声明、读取和关闭游标
- 理解游标和一次性查询的区别
- 能避免长时间打开游标

## 使用游标

```sql
BEGIN;

DECLARE note_cursor CURSOR FOR
SELECT id, title
FROM notes
ORDER BY id;

FETCH 10 FROM note_cursor;

CLOSE note_cursor;

COMMIT;
```

这会先声明游标，再读取 10 行，最后关闭游标。

## 适合场景

- 结果集比较大
- 希望分批处理
- 客户端不能一次接收全部结果
- 不适合长时间占用事务

## 容易混淆的词

| 词 | 新手解释 |
| --- | --- |
| 游标 | 分批读取结果的位置 |
| `DECLARE` | 声明游标 |
| `FETCH` | 从游标读取一批结果 |
| `CLOSE` | 关闭游标 |

## 练习题

1. 游标适合一次性读取全部数据，还是分批读取？
2. `FETCH 10` 表示读取多少行？
3. 游标长期不关闭好吗？
4. 游标通常要放在事务里理解吗？

::: tip 提示
游标解决“分批读”，不是让慢查询自动变快。
:::

::: details 答案
1. 分批读取。
2. 10 行。
3. 不好。
4. 要。
:::

## 常见坑

- 游标开着不关闭
- 事务长期占用资源
- 用游标掩盖本该优化的查询
- 分批读取时没有稳定排序

## 先记住这三句

- 游标用于分批读。
- `FETCH` 读取下一批结果。
- 游标不要长时间打开。
