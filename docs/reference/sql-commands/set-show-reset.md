# SET、SHOW、RESET 速查

`SET`、`SHOW`、`RESET` 用来查看和调整会话参数。它们常用于临时改变当前连接的行为。

## 你学完能干什么

- 能查看当前参数值
- 能临时修改会话参数
- 知道如何恢复默认值
- 能区分会话设置和永久配置

## 查看参数

```sql
SHOW timezone;
SHOW search_path;
```

## 修改和恢复

```sql
SET timezone = 'Asia/Shanghai';

RESET timezone;
```

`SET` 默认影响当前会话，不等于永久修改服务器配置。

## 常见用途

- 临时调整时区
- 查看当前 `search_path`
- 调试某个参数对查询的影响
- 在事务内临时改变行为

## 容易混淆的词

| 词 | 新手解释 |
| --- | --- |
| `SHOW` | 查看参数值 |
| `SET` | 修改当前会话参数 |
| `RESET` | 恢复参数默认值 |
| 会话 | 当前连接期间的上下文 |

## 练习题

1. 查看当前时区用 `SHOW` 还是 `SET`？
2. `SET timezone = ...` 默认是永久改配置吗？
3. 恢复参数默认值用什么命令？
4. `search_path` 和模式查找顺序有没有关系？

::: tip 提示
先把 `SET` 理解成“当前连接里的临时设置”。
:::

::: details 答案
1. `SHOW`。
2. 不是，默认影响当前会话。
3. `RESET`。
4. 有。
:::

## 常见坑

- 以为 `SET` 一定永久生效
- 改了 `search_path` 后找不到对象
- 在一个连接里改参数，却期待其他连接也变化
- 忘记把临时设置恢复

## 先记住这三句

- `SHOW` 看参数。
- `SET` 改当前会话。
- `RESET` 恢复默认值。
