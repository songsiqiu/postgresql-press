# INSERT 速查

`INSERT` 用来向表里插入新数据。新手重点要看清列名、值和约束错误。

## 你学完能干什么

- 能插入一行数据
- 能一次插入多行数据
- 知道插入时可能触发约束检查
- 能理解 `RETURNING` 的用途

## 插入一行

```sql
INSERT INTO demo_tags (name)
VALUES ('postgresql');
```

这里明确写出列名 `name`，再给出对应的值。

## 插入多行并返回结果

```sql
INSERT INTO demo_tags (name)
VALUES ('sql'), ('index'), ('transaction')
RETURNING id, name;
```

`RETURNING` 可以把刚插入的数据返回出来，常用于拿到新生成的主键。

## 容易混淆的词

| 词 | 新手解释 |
| --- | --- |
| 列清单 | `INSERT INTO` 后面写的列名 |
| 值清单 | `VALUES` 里的具体值 |
| 默认值 | 没传值时由数据库填入的值 |
| `RETURNING` | 把插入后的结果返回 |

## 练习题

1. `INSERT` 是新增数据还是修改已有数据？
2. 为什么建议写清楚列名？
3. `RETURNING id` 常用来拿什么？
4. 如果插入重复的唯一值，数据库可能会报错吗？

::: tip 提示
先写列名，再按同样顺序写值，最不容易看错。
:::

::: details 答案
1. 新增数据。
2. 避免表结构变化或值顺序错误导致插入错列。
3. 新生成的主键。
4. 可能会，因为唯一约束会检查重复。
:::

## 常见坑

- 不写列名，只按位置猜值
- 插入数据违反非空、唯一或外键约束
- 忘记处理插入失败后的业务结果
- 以为插入成功就一定能在只读副本马上读到

## 先记住这三句

- `INSERT` 负责新增行。
- 列名和值要一一对应。
- 约束会在插入时保护数据。
