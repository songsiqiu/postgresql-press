# 物化视图

物化视图像“保存了查询结果的视图”。它能加快一些复杂查询，但需要刷新，数据不会自动永远保持最新。

## 你学完能干什么

- 知道普通视图和物化视图的区别
- 能理解为什么物化视图需要刷新
- 知道它适合报表和复杂查询缓存
- 不会把它当成实时数据表

## 普通视图和物化视图

| 类型 | 新手理解 |
| --- | --- |
| 普通视图 | 保存查询定义，每次查询时再执行 |
| 物化视图 | 保存查询结果，需要刷新 |

## 一个例子

```sql
CREATE MATERIALIZED VIEW user_note_counts AS
SELECT user_id, count(*) AS note_count
FROM notes
GROUP BY user_id;
```

刷新：

```sql
REFRESH MATERIALIZED VIEW user_note_counts;
```

## 适合什么

- 报表查询
- 复杂聚合
- 不要求实时最新的数据
- 可以接受定时刷新

## 练习题

1. 物化视图保存的是查询定义还是查询结果？
2. 为什么物化视图需要刷新？
3. 它适合强实时数据吗？
4. 普通视图和物化视图最大区别是什么？

::: tip 提示
物化视图用“新鲜度”换“查询速度”，要先确认业务能不能接受。
:::

::: details 答案
1. 查询结果。
2. 底层数据变了，保存的结果不会自动同步成最新。
3. 不太适合。
4. 普通视图每次执行查询，物化视图保存结果。
:::

## 常见坑

- 以为物化视图会自动实时更新
- 忘记设计刷新时机
- 把需要实时一致的数据放进物化视图

## 先记住这三句

- 物化视图保存查询结果。
- 物化视图需要刷新。
- 它适合报表和复杂查询缓存。
