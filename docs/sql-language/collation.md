# 排序规则

排序规则决定文本怎么比较和排序。它会影响 `ORDER BY`、大小写、重音字符和不同语言文本的顺序。

## 你学完能干什么

- 知道排序规则影响文本比较和排序
- 能理解为什么同样的数据在不同环境排序可能不同
- 知道建库和建索引时要关注排序规则
- 能避免把文本排序差异当成 SQL 写错

## 一个例子

```sql
SELECT name
FROM users
ORDER BY name;
```

这条 SQL 的结果顺序不只由字母本身决定，还会受到数据库的排序规则影响。

如果应用需要稳定的跨环境排序，就要明确数据库和列使用的排序规则。

## 常见影响

| 场景 | 影响 |
| --- | --- |
| `ORDER BY name` | 文本排序顺序 |
| `WHERE name > 'm'` | 文本比较规则 |
| 唯一索引 | 某些排序规则下大小写或等价字符判断可能不同 |
| 多语言文本 | 不同语言的排序习惯不同 |

## 容易混淆的词

| 词 | 新手解释 |
| --- | --- |
| 排序规则 | 文本比较和排序的规则 |
| 字符集 | 字符如何编码保存 |
| 大小写敏感 | 是否区分大小写 |
| 本地化 | 按语言地区习惯处理文本 |

## 练习题

1. 排序规则主要影响数字排序还是文本排序？
2. 同样的 `ORDER BY name` 在不同环境结果可能不同吗？
3. 字符集和排序规则是一回事吗？
4. 多语言系统为什么要关注排序规则？

::: tip 提示
看到文本比较、文本排序和唯一判断，就要想到排序规则。
:::

::: details 答案
1. 文本排序。
2. 可能。
3. 不是。
4. 不同语言对字符顺序和等价判断可能不同。
:::

## 常见坑

- 以为文本排序只按字符编码
- 开发和生产排序规则不一致
- 多语言系统没有提前确定排序口径
- 忽略排序规则对索引和唯一判断的影响

## 先记住这三句

- 排序规则影响文本比较。
- 字符集和排序规则不是一回事。
- 多语言和跨环境系统要提前统一口径。
