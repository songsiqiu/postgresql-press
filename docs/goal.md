# 目标

这个站点的目标很明确：

参考 [PostgreSQL 官方文档](https://www.postgresql.org/docs/)，把它完整翻译并改造成一套适合新手学习的中文网站。

## 最终形态

- 覆盖官方文档主线内容
- 中文表达清楚、准确、少术语堆叠
- 每个章节都有新手导读和官方主题对应关系
- 能按学习路线阅读，也能按官方目录查阅
- 后续版本更新时能继续增量校对

## 本阶段完成标准

- 首页说明站点定位
- 导航按新手路线和官方目录分层
- 官方目录映射覆盖主要文档板块
- 核心入门页有可阅读内容，不只是空标题
- 翻译规范和翻译计划能指导后续补全
- 项目可以正常构建并推送到 Git 仓库

## 后续补齐方式

后续不要一次性铺满空页面，而是按“官方章节映射 -> 新手导读 -> 正文翻译 -> 示例校对 -> 构建验证”的顺序逐章补。
